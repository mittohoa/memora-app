## Cài đặt (Android)
1. Tải file `.apk` ở trên.
2. Mở file → cho phép "Cài từ nguồn không xác định" nếu được hỏi.
3. Cài & mở app.

App tự kiểm tra bản mới qua `version.json` và báo trong app khi có bản cập nhật.
