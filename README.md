## Cài đặt (Android)
1. Tải file `.apk` ở trên.
2. Mở file → cho phép "Cài từ nguồn không xác định" nếu được hỏi.
3. Cài & mở app.

Từ trong app: khi có bản mới, banner ở Trang chủ sẽ **tải ngầm và tự bật cài đặt** (không cần mở trình duyệt).
